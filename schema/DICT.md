# 简明词表

> 受控词典（领域术语表）。本文件定义 Wiki 中的标准术语。
> LLM 在写入 Wiki 时，必须使用本表中的标准术语，
> 所有同义表达统一替换为标准术语。
> 本表随着 Wiki 的增长持续更新。

---

## 使用规则

1. 一个概念只有一个**标准术语**。
2. 所有**同义表达**在 Wiki 页面中统一替换为标准术语。
3. 新术语加入 Wiki 前，先检查是否已有对应条目。
4. 如果新概念没有对应条目，创建新条目并定义。

## 一、大语言模型相关

| 标准术语 | 标准英文名 | 缩写 | 同义表达（统一替换为标准术语） | 定义 |
|---------|-----------|------|------------------------------|------|
| 大语言模型 | Large Language Model | LLM | 大模型、大型语言模型、语言大模型、LLM模型 | 一种基于大规模文本数据训练的人工智能模型，能够生成和理解人类语言 |
| 检索增强生成 | Retrieval-Augmented Generation | RAG | RAG技术、检索增强、检索式生成 | 一种将信息检索与文本生成相结合的技术，系统先从文档库中检索相关内容，再提供给语言模型以生成更准确的答案 |
| 提示词 | Prompt | - | 提示、prompt | 输入给大语言模型的文本，用于指导模型生成特定输出 |
| 上下文窗口 | Context Window | - | 上下文长度、token窗口 | 大语言模型在单次推理中能够处理的最大 token 数量 |
| 微调 | Fine-tuning | - | 精调、fine-tune | 在预训练模型的基础上，使用特定数据进一步训练，以适应特定任务 |
| 智能体 | Agent | - | 代理、AI代理、LLM代理 | 能够自主感知环境、做出决策并执行行动的人工智能系统 |
| Token | Token | - | 词元、令牌 | 大语言模型处理文本的基本单位，可以是一个字、一个词或一个词的一部分 |

## 四、方法与概念

| 标准术语 | 英文 | 同义表达 | 定义 |
|---------|------|---------|------|
| 受控语言 | Controlled Language | - | 一套对词汇、语法和风格有严格限制的语言规范，目的是提高清晰度和减少歧义 |
| ASD-STE100 | ASD-STE100 | STE100、STE | 由 ASD（航空航天与国防协会）制定的简化技术英语规范，最初用于航空维修文档 |
| 一词一义原则 | One Word, One Meaning | - | 受控语言的核心原则之一，规定每个术语只能有一个含义 |

## 术语维护说明

- 新增术语时，先确认是否已有同义的标准术语。
- 如果确实是新概念，添加到对应分类的末尾。
- 每个术语必须包含：标准术语、英文名（如有）、缩写（如有）、同义表达、定义。
- 术语的定义本身也必须符合简明表达规范。

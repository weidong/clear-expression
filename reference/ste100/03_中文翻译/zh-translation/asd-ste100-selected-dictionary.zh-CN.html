🔨 一、动词（30 个）

动词是 STE 规范的核心。STE 严格限制可以使用的动词及其形态， 只允许使用：动词原形、祈使形式、一般现在时。这大大降低了表达的复杂性。

批准词 中文释义 STE 例句（中 / 英）
USEv. 使用（employ for a purpose） 使用正确的工具来执行该步骤。
Use the correct tool to do the step.
DOv. 做、执行（perform an action） 执行泄漏测试。
Do the leak test.
MAKEv. 使、制作（cause to be） 确保表面清洁。
Make sure that the surface is clean.
PUTv. 放、放置（move to a position） 将文件放入指定目录。
Put the file in the specified directory.
SETv. 设置（adjust to a value） 将参数设置为默认值。
Set the parameter to the default value.
STARTv. 启动（begin to operate） 启动应用程序。
Start the application.
STOPv. 停止（cease operation） 如果出现错误，立即停止操作。
If an error occurs, stop the operation immediately.
CHECKv. 检查（examine if correct） 检查配置文件是否完整。
Check that the configuration file is complete.
INSTALLv. 安装（put in position for use） 在系统上安装依赖包。
Install the dependency package on the system.

📋 二、名词（25 个）

STE 中的名词分为批准名词和技术名词。批准名词是词典中明确批准的通用名词。 技术名词是各领域的专有名词（如"数据库""API"），不在批准词列表中但允许使用。

SYSTEMn. 系统（assembly of parts that work together） 该系统由三个模块组成。
The system has three modules.
DATAn. 数据（facts / information） 数据存储在数据库中。
The data is stored in the database.
INFORMATIONn. 信息（knowledge / facts） 页面包含有关错误的信息。
The page has information about the error.
FUNCTIONn. 功能、函数（purpose / normal operation） 此函数返回一个布尔值。
This function returns a boolean value.
VALUEn. 值、数值（quantity / magnitude） 变量的默认值为零。
The default value of the variable is zero.
PARAMETERn. 参数（value that can be adjusted） 输入参数决定输出结果。
The input parameters determine the output.
RESULTn. 结果（outcome / product） 结果显示在屏幕上。
The result is shown on the screen.
PROBLEMn. 问题（difficulty / question） 如果遇到问题，请查阅文档。
If you find a problem, refer to the documentation.
SOLUTIONn. 解决方案（answer / way to solve） 该问题有三种可能的解决方案。

CODEn. 代码（set of program instructions） 审查代码以查找错误。

🏷️ 三、形容词（20 个）

STE 限制形容词的使用以减少歧义。只有明确批准的形容词才能使用， 且通常只允许原级形式（不用复杂的比较级/最高级变化）。

批准词 中文释义 例句
CORRECTadj. 正确的（right / accurate） 输入正确的用户名。
Enter the correct username.
INCORRECTadj. 不正确的（wrong） 如果密码不正确，访问将被拒绝。
If the password is incorrect, access is denied.
DEFAULTadj. 默认的（standard / initial） 使用默认设置。
Use the default settings.
DIFFERENTadj. 不同的（not the same） 两种方法产生不同的结果。
The two methods give different results.
SAMEadj. 相同的（identical） 所有用户使用相同的接口。
All users use the same interface.
NECESSARYadj. 必要的（needed / required） 只安装必要的组件。
Install only the necessary components.
IMPORTANTadj. 重要的（of great value） 保存你的工作很重要。
It is important to save your work.
POSSIBLEadj. 可能的（able to be done） 可以通过命令行完成配置。
Configuration is possible through the command line.
IMPOSSIBLEadj. 不可能的（not possible） 没有密码就不可能访问。
Access is impossible without a password.
AVAILABLEadj. 可用的（ready for use） 有三种可用的选项。
Three options are available.
RELEVANTadj. 相关的（related / applicable） 有关更多信息，请参阅相关章节。
For more information, refer to the relevant section.
SPECIFICadj. 特定的、具体的（exact / particular） 为特定任务选择合适的工具。

AUTOMATICadj. 自动的（self-acting） 系统自动执行备份。
The system does the backup automatically.
MANUALadj. 手动的（done by hand） 如果自动模式失败，使用手动模式。

FULLadj. 完整的（complete） 完整列表请参阅附录。

MAXIMUMadj. 最大的（greatest possible） 最大文件大小为 100 MB。

Enter the value in the corresponding field.

🔗 四、副词 / 介词 / 连词（15 个）

这些连接词和修饰词看似不起眼，但是句子结构的"骨架"。 STE 对它们的使用有严格限制，目的是让句子结构简单明了。

FIRST adv. 首先、第一 用于步骤编号或排序。
THEN adv. 然后 表示顺序。注意：不能用来表示"因此"。
ALSO adv. 也 表示补充。
ONLY adv. 只、仅仅 表示限制。
FULLY adv. 完全地 完全关闭系统后再断开连接。
Fully close the system before you disconnect.
IMMEDIATELY adv. 立即 如果发生泄漏，立即关闭阀门。

CORRECTLY adv. 正确地 确保电缆正确连接。
Make sure that the cable is correctly connected.
BEFORE conj. 在……之前 开始之前，请阅读说明。
Before you start, read the instructions.
AFTER conj. 在……之后 完成后保存文件。
Save the file after you finish.
WHEN conj. 当……时 绿灯亮起时，设备就绪。
When the green light comes on, the equipment is ready.
IF conj. 如果 如果出现错误，请重新启动。

BECAUSE conj. 因为 因为内存不足，操作失败。

📖 六、使用说明

💡 批准词 vs 非批准词

批准词：STE 词典中批准使用的词，有明确的批准含义。在词典中以全部大写显示。

非批准词：STE 词典中不批准使用的词，通常给出一个或多个批准替代词。在词典中以小写显示。

🔑 一词一义原则

每个批准词只有一个批准含义。如果一个词在日常英语中有多个含义，在 STE 中只能使用其批准的那个含义。

例如：FOLLOW 的批准含义只有"跟随"（come after），不能用"follow the instruction"（遵循指示），应该说 Obey the instruction。

🔧 技术名词和技术动词

有些词虽然不在批准词列表中，但如果它们是：

① 你所在领域的标准技术名词   ② 简短（不超过 3 个词）   ③ 清晰易懂

那么可以作为"技术名词"或"技术动词"使用。但必须保持一致——同一个东西全程用同一个名称。

浓度调节指南

在 AI 场景下，不必追求 100% 严格的 STE 合规。根据场景灵活调节：

场景 推荐浓度 说明
技术文档 / 操作手册 100% 追求精确性和可维护性
知识库 / 概念说明 80% 清晰为主，适当灵活
日常交流 / 邮件 50% 保留核心原则，自然表达
创意写作 / 文章 20-30% 只借鉴短句和结构清晰的思路

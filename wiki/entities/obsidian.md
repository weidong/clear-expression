# Obsidian

## 描述

Obsidian 是一款笔记软件。它基于本地 Markdown 文件。
它支持双向链接和图谱视图。用户拥有自己的数据，所有文件都存储在本地。

## 核心功能

1. **双向链接**：自动显示指向当前页面的其他页面 [1]。
2. **图谱视图**：以网络图形式展示笔记之间的关系。
3. **插件系统**：用户可以安装第三方插件扩展功能。
4. **画布功能**：在无限画布上组织笔记和图片。
5. **模板**：支持页面模板，快速创建标准化页面。
6. **搜索**：强大的全文搜索和标签搜索。

## 在本知识库中的用途

- 作为简明表达规范库的前端阅读界面。
- 查看 raw/ 目录中的原始资料。
- 浏览 wiki/ 目录中的编译页面。
- 使用 Web Clipper 插件剪藏网页文章。
- 使用 Dataview 插件进行动态查询。

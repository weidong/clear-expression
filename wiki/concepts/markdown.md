# Markdown

## 定义

Markdown 是一种纯文本标记语言。它用简单符号表示标题、列表与链接。

## 特点

- 文件是纯文本，任何编辑器都能打开。
- 结构清晰，适合版本管理。
- 转换方便，可输出网页与文档。

## 局限

标准不统一。不同工具对表格与脚注的支持不一致。
